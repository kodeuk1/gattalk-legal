개인정보처리방침

시행일: 2026년 8월 16일

OnStage는 사용자를 얼굴로 식별하거나 타인과 비교하지 않고, 기기 안에서 계산한 자세 좌표로 자신의 변화만 확인하도록 돕습니다.

1. 수집하는 정보

계정 이메일과 이름, 학원·수업·초대 관계, 기기에서 추출한 관절 좌표 시퀀스, 담당 강사의 ROM·박자·축·표현력 평가와 코멘트, 별도 동의가 있는 경우 리포트용 정지 이미지 2장을 처리할 수 있습니다.

원본 촬영 영상은 이용자의 기기에만 보관하며 서버로 업로드하지 않습니다.

2. 얼굴 주변 자세 좌표 처리

OnStage는 얼굴 인식, 본인 확인, 감정 분석 또는 얼굴 식별자를 만들지 않습니다. 연습 영상의 자세를 분석할 때 MediaPipe Pose Landmarker가 프레임별 33개 자세 좌표를 기기 안에서 계산하며, 이 중 0~10번 11개는 코·눈·귀·입 주변의 대략적인 위치 좌표입니다. 얼굴 이미지, 얼굴 메시, Face ID 데이터 또는 생체 식별 템플릿은 생성하거나 수집하지 않습니다.

이 좌표와 원본 영상은 앱 전용 저장 공간에만 저장되고 OnStage 서버, Supabase, Google 또는 기타 제3자에게 전송하거나 공유하지 않습니다. Google MediaPipe 라이브러리는 기기에서 오프라인으로 실행됩니다. 좌표와 영상은 사용자가 앱의 ‘내 정보 → 계정과 데이터 삭제’에서 계정을 삭제하거나 앱을 삭제할 때까지 보관되며, 해당 삭제 시 기기에서 제거됩니다.

3. 이용 목적

회원 인증, 역할별 기능 제공, 이용자 본인의 이전 기록과 비교한 성장 리포트 생성, 초대 및 리포트 공유, 고객지원과 서비스 안전성 개선에 이용합니다. 사용자 간 순위·백분위·절대 100점 점수 산출에는 사용하지 않습니다.

4. 보관과 파기

계정과 학원 기록은 서비스 제공 기간 동안 보관합니다. 계정을 삭제하면 관련 계정 정보는 즉시 삭제 또는 법적 의무 범위에서 분리 보관하며, 기기의 촬영 영상과 자세 좌표를 포함한 로컬 기록도 앱 영역에서 삭제합니다. 만료된 초대와 공유 링크는 정책에 따라 폐기합니다.

5. 처리 위탁과 국외 처리

인증·데이터베이스·파일 저장을 위해 Supabase를, 앱 빌드와 배포를 위해 Expo를, 공개 정책·지원 페이지 제공을 위해 GitHub Pages 또는 OpenAI Sites 기반 호스팅을 이용할 수 있습니다. 기기 안의 원본 영상과 자세 좌표는 이러한 사업자에게 전송되지 않습니다. 각 제공자는 서비스 운영에 필요한 범위에서만 정보를 처리합니다.

6. 이용자의 권리

이용자는 앱의 ‘내 정보 → 계정 삭제 화면 열기 → 계정 삭제 시작’에서 고객센터나 이메일 요청 없이 계정과 연결 데이터를 직접 영구 삭제할 수 있으며, 개인정보 열람·정정·삭제·처리 제한을 고객지원으로 요청할 수 있습니다. 계정 없이 받은 부모용 만료 링크는 별도의 부모 계정을 요구하지 않습니다.
